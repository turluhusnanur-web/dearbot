## ✨ Key Features

* 💬 **Real-time Interaction:** Smooth and quick responses designed for user engaging conversations.
* ⚡ **Lightweight Backend:** Powered by Python and Flask for optimized performance and low latency.
* 📱 **Responsive UI:** Clean, intuitive interface accessible across desktop, tablet, and mobile devices.
* ☁️ **Cloud Deployed:** Hosted continuously on Render for easy availability.
